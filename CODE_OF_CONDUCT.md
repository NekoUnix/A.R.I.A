# Working together

Treat contributors and users respectfully. Discuss the code and observed behavior;
give specific, constructive feedback and make room for people learning the project.
Harassment, threats, discriminatory abuse, deliberate disruption and sharing
someone's private information without permission are not acceptable.

These expectations apply to repository issues, pull requests, reviews and project
discussions. Repository owner **NekoUnix** handles conduct concerns and may remove
content, limit participation or revoke access. For sensitive reports, ask the owner
for a private channel before sharing details. Decisions should be proportionate
to the behavior and protect the people involved.
