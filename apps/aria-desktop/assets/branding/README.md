# ARIA Studio mascot

The top-left header uses `vaelari-aria-mascot-256.png` and renders the text
`A.R.I.A.` / `AVATAR STUDIO` as UI text so it remains crisp and accessible.
`vaelari-aria-mascot-master.png` is the transparent full-resolution source for
future exports. The supplied Vaelari AI character sheet was used only as an
identity reference; the private sheet is not part of this repository.

The mascot was generated with the built-in image generation tool. Prompt:

> Create an original transparent chibi head-and-shoulders icon of Vaelari,
> preserving her fluffy lavender-pink hair with icy blue tips and top bun,
> angular flat black mechanical cat ears with magenta/cyan panels, cyan-green
> eyes, and black/magenta futuristic collar with purple tech gem. Calm,
> mischievous expression; crisp deep-purple anime outlines and simplified
> shapes readable at small size. No text, background, border or watermark.

The header asset was downsampled to 256×256 with Lanczos filtering and retains
transparency. The art and lockup are specific to the owner's Vaelari character.
